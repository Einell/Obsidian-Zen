# 禅模式

写笔记时收起周围的界面，并让文件列表只留下当前文件夹。

在左侧边栏顶栏（文件列表、搜索、书签那一行）有一个「禅」按钮。点一次进入，再点一次或按 Esc 退出。需要 Obsidian 1.7.2 或更高版本。

## 进入之后

- 文件列表只显示目标文件夹和它里面的内容。父级目录、旁边的目录，以及这个范围以外的文件都会藏起来。
- 左栏、左侧功能区和底部状态栏收起。编辑区顶部的笔记标签也藏起来。
- 展开和收起右栏的按钮留着。笔记正文、行内标题和属性留着。笔记标题栏可以拖动窗口。
- 指针移到窗口左边缘时，左栏会临时出现，可以再点「禅」退出。指针离开后，左栏收回。

目标文件夹优先用文件列表里当前选中的文件夹。没有选中文件夹时，用当前笔记所在的文件夹。笔记在库根目录时不聚焦文件夹，界面仍会收起。没有选中文件夹、也没有打开笔记时，不会进入。

这些状态只在当前会话里有效，关掉 Obsidian 或退出禅模式后会恢复，不会写入插件配置。

## 安装

这个插件还没有上架官方社区插件市场。从 [Releases](https://github.com/Einell/Obsidian-Zen/releases) 下载最新版本里的 `main.js`、`manifest.json` 和 `styles.css`。

1. 在库文件夹里打开 `.obsidian/plugins/`。没有这个目录时，先在 Obsidian 里打开一次「设置 → 第三方插件」。
2. 新建文件夹 `zen-mode`，把上面三个文件放进去。
3. 重启 Obsidian，或在第三方插件列表里重新加载。
4. 关闭安全模式，启用「禅模式」。

装好后，左侧边栏顶栏会出现「禅」。
